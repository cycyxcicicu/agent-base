## 2. Ranh Giới Hợp Đồng (Contract & Happy Path)
- **Đầu vào (Request Payload)**:
  ```json
  { "email": "user@example.com", "password": "SecurePassword123!" }
  ```
- **Đầu ra (Response Payload)**:
  ```json
  { "status": "success", "user": { "id": "usr_01", "email": "user@example.com" }, "token": "jwt_token_sample" }
  ```
- **Kịch bản Happy Path**: Gửi payload hợp lệ ➔ nhận HTTP 200 kèm JWT ➔ client lưu session và redirect.
- **Tình huống biên (Edge Cases)**:
  - Email sai định dạng ➔ HTTP 400 kèm lỗi Zod validation rõ ràng dưới ô input.
  - Mật khẩu sai ➔ HTTP 401 không làm lộ email có tồn tại hay không.
