## Mục tiêu
Một nguồn khai báo node/cạnh bằng JSON; validator phát hiện link gãy, ID trùng, vòng, trạng thái sai, tài liệu lỗi thời. Đây là phần giá trị nhất của "Graph + Markdown" (PDF trang 15–18, 24). Python stdlib, không thêm dependency.

## Contract & Happy Path
- **Đầu vào**: JSON catalog (`schema_version:1`, node có `id TYPE:slug`, `kind`, `state`, `version`, `content_ref`, `content_sha256`, `provenance`, `owner_role`, `relations`).
- **Đầu ra**: `load_catalog(root) -> Catalog`; `validate(catalog, as_of) -> Diagnostics` (danh sách lỗi có mã, node, thông báo; exit-code logic để T-21 dùng).
- **Happy path**: catalog hợp lệ → 0 lỗi. Catalog có link tới node không tồn tại, cạnh `depends_on` tạo vòng, nội dung file đổi so với hash, đi thẳng `draft→approved` → mỗi trường hợp báo đúng một mã lỗi.
- **Dữ liệu thử**: tạo **inline trong test**, mô phỏng cấu trúc "bản đồ tài liệu + quy tắc ưu tiên khi mâu thuẫn" (kiểu GDT) bằng dữ liệu giả; không dùng nội dung hay tên thật của GDT (Q7.a).
