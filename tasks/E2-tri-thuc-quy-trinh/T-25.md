## Contract & Happy Path
- **Proof**: `schema_version`, `run_id`, `scenario_id`, `phase baseline|final`, thời gian UTC, `repo_revision`, `dirty_input_manifest`, `input_digest`, `commands` (argv list, cwd tương đối, timeout, exit code, hash stdout/stderr), `assertions` (expected/observed), `artifacts` (đường dẫn tương đối + sha256 + byte), `trace` (observed|reported), `cleanup`, `limitations`, `result pass|fail|inconclusive|skipped`. `additionalProperties:false`.
- **CLI**: `scripts/verify.py bootstrap|upgrade --evidence-root <dir> [--keep-fixture]`; **không nhận target thật**, fixture tự tạo bằng `TemporaryDirectory` có sentinel; không HOME/Downloads/cookies/mạng.
- **Bootstrap recipe**: cài vào thư mục trống → doctor → file phân phối đúng manifest → template không mang nội dung repo.
- **Upgrade recipe**: bootstrap bản baseline → sửa file dự án + file gây xung đột → chạy flow hiện có → **giữ tùy chỉnh, báo xung đột, dry-run không đổi bytes, chạy lại ra cùng kết quả**.
- **Happy path**: proof còn đọc được và hash khớp **sau cleanup**; proof bị sửa tay → `proof-check` báo lỗi.
