# Tuyển sinh liên tục Khóa API - Tích hợp hệ thống (học qua video)

*Tác giả: Đậu Thị Ngọc Ánh | Ngày đăng: 2024-07-09T02:46:00.000Z*

Sau 1 thời gian mở khóa IT cơ bản, với đối tượng học viên chủ yếu là BA, công việc hằng ngày trên công ty khá là bận rộn, nên việc sắp xếp học theo 1 giờ cố định của lớp học sẽ rất khó khăn. Kiến thức trong khóa IT cơ bản (gồm các kiến thức như API, Database, Lập trình cơ bản, Lập trình FrontEnd) khá là nặng, và có sự liên kết nhau giữa các buổi - Mỗi nội dung ERD và API có 4 buổi giảng dạy. Điều này làm cho các bạn học viên khi bị lỡ 1 buổi nào đó quay lại sẽ khó tiếp thu được và dần dần bỏ cuộc. Kiến thức trong khóa là những kiến thức rất hữu ích và sát với những gì bạn đi làm. Từ đó mình quyết định thay vì giảng dạy online trực tiếp thì mình chuyển thành khóa giảng dạy qua video kèm tương tác trao đổi để giải đáp các vấn đề từ học viên. Khi chuyển khóa học sang dạng tự học qua video thì mình chia thành 2 khóa: Khóa kiến thức cơ bản về database- SQL và Khóa về API - tích hợp hệ thống. Tách ra như thế này rất tiện cho nhu cầu của từng bạn, và chi phí bỏ ra sẽ được tách nhỏ ra nên phù hợp hơn với nhiều bạn.

Dưới đây là 1 số thông tin liên quan đến khóa học API và tích hợp hệ thống, còn thông tin liên quan tới khóa Database và SQL, các bạn có thể click [vào đây](https://m2mba.com/posts/012fcac0-ac6f-4fd2-9239-30eb69aa4512)

## 1.Nội dung khóa học

Khóa học được chia ra làm các phần quan trọng

- **Kiến thức cơ bản về API**: Định nghĩa về API
- Các thành phần của API
- **Kiến thức cơ bản về lập trình phục vụ xác định API**Kiến thức về biến, biến dạng mảng
- Toán tử số học, toán tử gán
- Câu lệnh If else, for loop
- **Kiến thức cơ bản về HTML phục vụ xác định API** : HTML là gì
- Thuộc tính của thẻ HTML
- Tìm hiểu về DOM
- **Xác định API trong 1 Usecase:**Cách quản lý dữ liệu trên Frontend
- Các bước xác định API trong 1 UC
- Demo thực hành xác định API
- Đặc tả API
- Các vấn đề phát sinh khi không thống nhất đặc tả
- **Các bước xây dựng API** Xác định xây dựng API mới/cũ trên hệ thống
- Thiết kế API
- Lập trình API
- Test API
- Các phương thực xác thực API
- **Tích hợp API**Các bước thực hiện trong dự án tích hợp kèm demo theo từng bước
- Xây dựng API để tích hợp với bên khác kèm demo
- Xử lý timeout khi tích hợp hệ thống
- Tích hợp với hình thức message queue
- Tích hợp với hình thức File FTP server
Chi tiết, chọn xem [chi tiết khóa học API tích hợp hệ thống](https://m2mba.com/courses/4)=>Nội dung khóa học

## **3.Hình thức học**

- Sau khi các bạn đăng ký và hoàn thành việc chuyển khoản, admin sẽ cấp share tài liệu và video liên quan tới khóa học. Các bạn chủ động sắp xếp lịch học của mình để hoàn thành khóa học
- Các bạn sẽ được share video và bài test theo từng phần**: **Điều này giúp đảm bảo các bạn đã nắm kiến thức cũ trước khi đi sang kiến thức mới. Sau khi hoàn thành bài test với mức Đạt, các bạn sẽ được share video tiếp theo. Trường hợp các bạn không đạt bài test, Mentor sẽ trao đổi meeting và giải đáp các thắc mắc cho các bạn ở buổi meeting định kỳ, sau đó các bạn sẽ làm lại bài test cũ (hoặc bài test mới 1 lần nữa) để được sang video tiếp theo. Thực sự kiến thức khóa rất hữu ích và chi tiết, nên mong các bạn không học vội vàng để rồi không lĩnh hội được kiến thức, và sớm bỏ cuộc
- Khóa học sẽ có group để giúp các học viên trao đổi các thắc khi cần thiết, hoặc các bạn chủ động comment trên bài viết của khóa học để được mentor giải đáp
- Sẽ có bài test cuối khóa để kiểm tra toàn bộ kiến thức của các bạn đã học trong khóa

Bạn nào cần cấp ảnh chứng nhận, mình vẫn sẽ hỗ trợ cấp nhé (nhưng chứng nhận không có dấu đỏ)
