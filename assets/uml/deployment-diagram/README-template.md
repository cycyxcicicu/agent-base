# Mẫu chuẩn của dự án cho loại này

- Công cụ: `python3 ~/Documents/agent-base/scripts/ve-so-do.py` (type `deployment`).
- `template.json` là JSON mẫu (cùng nội dung lệnh `ve-so-do.py --mau deployment`; ví dụ minh họa, KHÔNG phải dữ liệu thật); `template.drawio` và `template.png` sinh từ JSON đó.
- Mẫu phân tích, phiếu và khung JSON để điền: `agents/knowledge/diagrams/mau-phan-tich/deployment.md`.
- Quy trình và chuẩn: `agents/knowledge/diagrams/quy-trinh-ve-so-do-bang-json.md`.
- `spec.md` và `images/` là tài liệu và ảnh UML chung (uml-diagrams.org) để tra ký hiệu, KHÔNG phải chuẩn dự án; khi khác thì theo chuẩn dự án.
