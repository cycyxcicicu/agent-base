Title: UML state machine diagrams examples

URL Source: https://www.uml-diagrams.org/state-machine-diagrams-examples.html

Markdown Content:
Here we provide several examples of [state machine diagrams](https://www.uml-diagrams.org/state-machine-diagrams.html):

  

![Image 1: Next](https://www.uml-diagrams.org/images/next-state.png)[Water Phase Diagram as State Machine](https://www.uml-diagrams.org/examples/water-phase-uml-state-machine-diagram-example.html)

**Purpose**: An example of water phase diagram represented as UML state machine diagram.

**Summary**: Water can exist in several states - liquid, vapor, solid, and plasma. Several transitions are possible from one state to another.

[![Image 2: Water phase diagram as UML state machine diagram example.](https://www.uml-diagrams.org/thumbnails/water-phase-uml-state-machine-diagram-example.png)](https://www.uml-diagrams.org/examples/water-phase-uml-state-machine-diagram-example.html)

  

![Image 3: Next](https://www.uml-diagrams.org/images/next-state.png)[Bank ATM behavioral state machine UML diagram example](https://www.uml-diagrams.org/bank-atm-uml-state-machine-diagram-example.html?context=stm-examples)

**Purpose**: An example of UML [behavioral state machine](https://www.uml-diagrams.org/state-machine-diagrams.html#behavioral-state-machine) diagram describing Bank Automated Teller Machine (ATM) top level state machine.

**Summary**: ATM is initially turned off. After the power is turned on, ATM performs startup action and enters **Self Test** state. If the test fails, ATM goes into **Out of Service** state, otherwise there is **triggerless transition** to the **Idle** state. In this state ATM waits for customer interaction.

[![Image 4: Bank ATM behavioral state machine UML diagram example.](https://www.uml-diagrams.org/thumbnails/bank-atm-uml-state-machine-diagram-example.png)](https://www.uml-diagrams.org/bank-atm-uml-state-machine-diagram-example.html?context=stm-examples)

  

![Image 5: Next](https://www.uml-diagrams.org/images/next-state.png)[Online shopping user account UML state machine diagram example](https://www.uml-diagrams.org/examples/online-shopping-user-account-state-diagram-example.html?context=stm-examples)

**Purpose**: An example of user account life cycle in the context of [online shopping](https://www.uml-diagrams.org/examples/online-shopping-example.html), and shown as UML [protocol state machine](https://www.uml-diagrams.org/protocol-state-machine-diagrams.html#protocol-state-machine) diagram.

**Summary**: Every company having customers maintains customer accounts and supports a complete life cycle of the account from its creation until it is closed. There are differences in what are the stages (states) in the account's life cycle, and what are conditions or events causing account to change its state.

[![Image 6: User account UML state machine diagram example.](https://www.uml-diagrams.org/thumbnails/online-shopping-user-account-state-diagram-example.png)](https://www.uml-diagrams.org/examples/online-shopping-user-account-state-diagram-example.html?context=stm-examples)

  

![Image 7: Next](https://www.uml-diagrams.org/images/next-state.png)[Java EJB life cycle of a session object UML state machine example](https://www.uml-diagrams.org/java-ejb-state-machine-diagram-example.html?context=stm-examples)

**Purpose**: Life cycle of an EJB session object is shown from the point of view of a local or remote client using the EJB 2.1 and earlier client view API.

**Summary**: A session object does not exist until it is created. When a client creates a session object, the client has a reference to the newly created session object’s component interface.

[![Image 8: Java EJB life cycle of a session object UML state machine example.](https://www.uml-diagrams.org/thumbnails/java-session-ejb-uml-state-machine-example.png)](https://www.uml-diagrams.org/java-ejb-state-machine-diagram-example.html?context=stm-examples)
