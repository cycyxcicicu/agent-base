# Danh sách CHÍNH THỨC phần "khung" của agent-base mang sang dự án khác.
# Được đọc bởi scripts/bootstrap-project.py (cài sang dự án) và scripts/agent-base-diff.py (so sánh, đồng bộ ngược).
# Thứ không có trong file này (cookies/, tools/ trừ tools/viewer/, src/, tests/, tasks/T-*, nội dung docs/...) là của riêng repo agent-base, KHÔNG mang sang.
#
# Cú pháp: <loại> <đường dẫn>   (thư mục kết thúc bằng /, luôn bỏ qua __pycache__)
#   copy       copy sang dự án; là nguồn dùng chung, sửa ở dự án thì phải đưa ngược về agent-base
#   template   copy sang dự án làm mẫu, dự án tự điền nội dung riêng; không so sánh (được đặt trước copy để thắng)
#   generated  copy sang dự án nhưng là file SINH RA bởi scripts/sync-adapters.py; không so sánh, không đưa ngược
#   gitonly    chỉ copy khi --mode git (dễ trùng file thật của dự án); không bao giờ ghi đè
#   fresh      tạo mới từ mẫu trống trong bootstrap-project.py (không mang nội dung của agent-base)
#   mkdir      tạo thư mục trống
#
# Thêm file hoặc thư mục dùng chung mới vào agent-base thì PHẢI thêm vào đây, nếu không dự án sau sẽ không có.
